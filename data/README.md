# Data

Raw and processed datasets for the ML loan recommendation model.

## Structure
```
data/
├── raw/          ← Original datasets (CSV, JSON)
├── processed/    ← Cleaned and feature-engineered data
└── README.md
```

> [!WARNING]
> Do NOT commit sensitive or personally identifiable data (PII) to this repository.
> Use anonymized/synthetic data for development and testing.
